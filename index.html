MODULE 01

公众号赛道定位工作台

用兴趣、能力、投入与商业目标，筛出更适合长期经营的公众号方向

十大赛道详细对比

1. 中老年情感 / 生活感悟

受众基数大、完读稳定，适合用真实故事和生活经验建立陪伴感。

核心优势 受众大、门槛低
变现方式 流量主、商业广告
难度 ★☆☆☆☆
稳定性 ★★★★☆
⚠️ 内容同质化明显，需要固定人物视角和真实细节，避免空泛说教。
选题方向 生活经历、家庭关系、晚年智慧
21天启动方案
  1. 拆解20篇高完读故事，确定3个固定栏目
  2. 发布5篇真实生活故事，测试人物与冲突类型
  3. 围绕高完读主题连续扩写6篇
  4. 复盘打开率与读完率，保留前2个栏目

2. 职场干货 / 国企职场

用户问题明确、付费意愿强，容易沉淀模板、课程和社群产品。

核心优势 需求明确、可系列化
变现方式 知识付费、社群服务
难度 ★★★☆☆
稳定性 ★★★★☆
⚠️ 必须有真实经验或可靠案例支撑，泛职场观点很难建立信任。
选题方向 沟通汇报、晋升路径、体制经验
21天启动方案
  1. 列出30个真实职场问题，按岗位和阶段分类
  2. 发布5篇问题解决型内容并附可执行清单
  3. 制作1份模板资料，测试用户领取意愿
  4. 根据高收藏问题规划首个10篇系列

3. 历史人文 / 典故科普

推荐

平台推荐较稳定、用户粘性强，内容资产可以长期复用，适合持续垂直运营。

核心优势 长尾稳定、生命周期长
变现方式 流量主、课程、出版
难度 ★★★☆☆
稳定性 ★★★★★
⚠️ 考据准确性决定账号生命力，必须标注可靠来源，避免戏说冒充史实。
选题方向 历史人物、典故出处、时代生活
21天启动方案
  1. 确定一个窄切口，建立30个选题的资料库
  2. 发布5篇"人物＋事件＋启示"样稿
  3. 固定史料来源与配图规范，形成写作模板
  4. 把高收藏主题扩展成8-10篇系列

4. 读书赛道

推荐

以书为内容锚点，适合书评、知识拆解和主题书单，能持续沉淀个人认知品牌。

核心优势 素材稳定、利于沉淀IP
变现方式 图书分销、读书营、课程
难度 ★★☆☆☆
稳定性 ★★★★★
⚠️ 只做摘抄很难形成辨识度，需要明确选书标准和自己的判断框架。
选题方向 主题书单、经典拆解、阅读方法
21天启动方案
  1. 选定一个阅读母题，建立20本核心书单
  2. 发布3篇深度拆解和2篇主题书单
  3. 测试"观点＋案例＋行动清单"内容模板
  4. 整理高收藏内容，设计首期共读主题

5. 家庭教育 / 育儿心得

女性受众集中、议题丰富，可连接教育产品和家庭服务。

核心优势 话题强、商业空间多
变现方式 教育服务、产品、广告
难度 ★★★☆☆
稳定性 ★★★★☆
⚠️ 避免绝对化教育结论；涉及儿童健康和心理问题时必须引用专业依据。
选题方向 亲子沟通、学习习惯、家庭关系
21天启动方案
  1. 聚焦一个年龄段，梳理20个高频家庭问题
  2. 发布5篇场景化解决方案
  3. 邀请目标家长反馈，修正表达与建议边界
  4. 围绕最高频问题制作7篇连续专题

6. 娱乐 / 剧评

受众关注度高、传播快，适合跟进热播作品和娱乐事件迅速获取流量。

核心优势 热点密集、传播性强
变现方式 流量主、品牌广告
难度 ★★☆☆☆
稳定性 ★★☆☆☆
⚠️ 高度依赖更新速度，素材版权和未经证实的娱乐信息需要严格把关。
选题方向 热播剧评、人物分析、行业观察
21天启动方案
  1. 锁定3部近期热播作品，建立追更日历
  2. 抢发6篇单点观点，测试标题与时效
  3. 将高流量剧评延伸为人物或主题系列
  4. 统计热点寿命，建立快稿与深稿双流程

7. 心理学 / 情绪疗愈

共鸣与收藏潜力强，适合围绕情绪管理、关系模式持续建立专业信任。

核心优势 收藏高、信任价值强
变现方式 课程、咨询、知识付费
难度 ★★★★☆
稳定性 ★★★★☆
⚠️ 需要清楚区分心理科普与临床诊疗，避免给出诊断或替代专业治疗。
选题方向 情绪调节、关系模式、自我探索
21天启动方案
  1. 明确科普边界，整理20个可引用的专业来源
  2. 发布5篇"场景＋机制＋练习"内容
  3. 用收藏率验证最强需求，不以焦虑营销
  4. 围绕高需求主题设计7天练习内容

8. 情感关系 / 婚恋经营

覆盖面广、互动天然强，适合用案例分析建立个人情感IP。

核心优势 互动强、需求广
变现方式 咨询、课程、社群、广告
难度 ★★☆☆☆
稳定性 ★★★★☆
⚠️ 不要承诺"挽回"等确定结果，案例要保护隐私并避免操控性建议。
选题方向 婚姻沟通、亲密关系、分手成长
21天启动方案
  1. 选定单身或已婚人群，收集30个真实困惑
  2. 发布5篇案例分析，强化观点边界
  3. 测试问答栏目，观察评论中的高频需求
  4. 将高互动问题扩展为关系沟通系列

9. 个人成长 / 认知提升

用户学习意愿强，适合用方法论和实践记录积累高价值个人IP。

核心优势 IP价值高、产品延展强
变现方式 课程、训练营、社群
难度 ★★★☆☆
稳定性 ★★★★☆
⚠️ 抽象概念容易变成正确的废话，需要真实实验、案例和可验证行动。
选题方向 认知模型、习惯系统、学习方法
21天启动方案
  1. 确定一个可验证的成长主题，设计21天实验
  2. 发布4篇方法文和1篇真实复盘
  3. 用读者行动反馈验证方法是否可执行
  4. 将有效方法整理成工具表和系列内容

10. 鸡汤人性

情绪共鸣强、覆盖广、创作门槛较低，容易获得点赞和转发。

核心优势 易传播、起步门槛低
变现方式 流量主、商业广告
难度 ★☆☆☆☆
稳定性 ★★★☆☆
⚠️ 同质化和低信任风险较高，建议用真实故事代替拼贴金句，避免标题过度承诺。
选题方向 人性观察、处世感悟、现实故事
21天启动方案
  1. 确定一种稳定叙事口吻，收集30个真实故事
  2. 发布6篇短故事，测试情绪和主题方向
  3. 淘汰低转发主题，增加具体人物与细节
  4. 把高传播主题做成固定栏目并控制同质化

MODULE 03 · 实操教程

WorkBuddy + Skill 写作

快速写出第 1 篇文章并发布 ｜ 从找热点、选对标、加载 Skill，到生成文章、植入人设、发布和转贴图

整体流程概览 5步走

① 热点库与Skill → ② 用Skill生成文章 → ③ 植入人设调优 → ④ 转发朋友圈 → ⑤ 一键转贴图

1

热点库与 Skill（热点规避）

使用今日热榜寻找对标内容。进入网站后选择"综合"，再点击"微信"。只要不是贴图类内容，也不涉及政治层面，就可以进入后续写作流程。

💡 热点规避原则：不选择贴图文章；不处理涉及政治的内容；医生、养生等涉及专业资质的内容也应谨慎避开。

1.1 找对标，定方向

第一步：在微信搜一搜寻找低粉爆文

  • 输入你所在领域的关键词，例如"收纳"
  • 选择"最热"，时间筛选为"最近半年"或"最近七天"
  • 重点寻找：粉丝不多（几千到几万）、发布篇数在300篇以下，但出现过万+爆文的账号
  • 这类账号是最值得学习的对象
💡 示例：搜索"收纳" → 点击"全部" → 选择"最热"与"最近七天"。找到文章《被网友的"短袖收纳"惊呆了，不花啥钱，几十件T恤搞得整整齐齐》，阅读量达到5w+。进入账号后发现只发布了87篇，其余文章平均只有两三位数阅读，其中却出现了一篇5w+，符合"低粉爆文"特征。

第二步：分类保存账号与爆文

  • 把找到的账号和爆文链接，分别转发到自己的"对标账号"群和"对标爆文"群
  • 小技巧：可以通过"面对面建群"创建只有自己一个人的群，也可以拉自己的小号，用来长期存放爆款文章

1.2 十大赛道 Skill 与下载教程

文档内含1000+技能包。根据自己的公众号赛道，选择同赛道Skill进行写作。

  • 打开公众号10赛道写作Skill合集 ↗
  • 鼠标移动到技能包位置，点击下载箭头，将所需技能包保存到电脑
2

用 Skill 生成文章

2.1 电脑端图文教程

第 1 步：把技能拖入 WorkBuddy 窗口

  1. 双击打开 WorkBuddy，点击"新建任务"
  2. 将默认权限改为"允许完全访问"
  3. 把挑选好的技能包拖入 WorkBuddy 窗口

第 2 步：复制文章链接，粘贴到 WorkBuddy

  1. 把热点库的链接复制到微信搜一搜并打开，点击"访问链接"，进入原文章
  2. 点击右上角"…" → 点击"复制链接"，获得短链接
  3. 把短链接发送给 WorkBuddy。初次使用耗时较长，预计需要15-17分钟
  4. 生成完成后，侧边栏会出现公众号文章3篇、朋友圈文案3条。三篇文章可分别发布到三个公众号
3

植入人设，调优初稿，降低同质化

Skill已内置基础人设，不修改也可以直接使用。如果希望文章更贴近自己，可以按以下步骤修改人设。

3.1 修改人设教程

  1. 点击"修改人设"，按模板填写基本信息：
我叫 XX，我生活的城市是 XX，我的职业是 XX， 我的经历是 XX，我的性格是 XX， 我的兴趣是 XX，我讨厌的是 XX。
  1. 填写完成后，点击右侧"复制提示词"。不要点击下方的"修改人设"，该按钮没有效果。
  2. 把复制的提示词发送到之前的 WorkBuddy 窗口
  3. WorkBuddy 提示完成后，人设即修改成功
4

把发布的文章转发到朋友圈

  1. 先发布 Skill 生成的文章，然后打开已发布文章，选择分享到朋友圈
  2. 在"交付总览"里找到朋友圈文案，选择合适的文案并复制
5

发布文章后一键转贴图

平台更新后，已发布文章可以一键转成贴图，方便获得多份内容收益。

  1. 发布文章后，系统提示"已自动将文章生成为贴图草稿"，点击"去查看"
  2. 打开赞赏
  3. 检查无误后点击"发表"
